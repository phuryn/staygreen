# Security

For a security problem, do not open a public issue. Use [private vulnerability reporting](https://github.com/phuryn/staygreen/security/advisories/new).

Issues are public. **Never paste a secret, service-role or restricted key, a token, a webhook or heartbeat URL, a signing secret or a header value, whether Staygreen issued it or another service did.** If you posted one, treat it as leaked: make sure the old value stops working wherever it is accepted, because issuing a new one doesn't always retire it.

Staygreen is not accepting pull requests or outside contributions at the moment.
